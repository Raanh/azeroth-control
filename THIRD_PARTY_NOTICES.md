# Third-party software

Azeroth Control is an independent installer and control application. It does
not include World of Warcraft clients, game data, MPQ/CASC archives, maps,
models, textures, Blizzard executables, accounts, or credentials.

During installation it can download third-party open-source projects directly
from upstream repositories. Those projects retain their own copyright and
license terms, including AzerothCore, mod-playerbots and selected modules.

The module catalog contains links and metadata only. Third-party source code is
not relicensed by Azeroth Control.
